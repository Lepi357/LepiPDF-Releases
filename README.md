# LepiPDF

**LepiPDF** es un visor y herramienta de productividad para archivos PDF en Windows, desarrollado por **Lepi Software / We-Soluciones**.

Pensado para uso cotidiano, soporte técnico, administración y trabajo con documentación, combina visualización, edición no destructiva, formularios, organización de páginas e integración con Windows.

## Versión actual

**LepiPDF 1.9.6**  
Windows 10 / 11 · 64 bits

## Funciones principales

- Visualización de archivos PDF con zoom, ajuste de ancho y ajuste de alto.
- Giro de visualización en pasos de 90°.
- Selección y copia de texto.
- Buscador con navegación automática entre resultados.
- Hipervínculos clickeables dentro del PDF.
- Resaltado de texto en distintos colores.
- Texto libre, etiquetas, fecha, rectángulos, líneas y flechas.
- Captura de áreas del PDF al portapapeles o PNG.
- Impresión con 1, 2 o 4 páginas por hoja.
- Impresión doble faz automática y manual.
- Formularios PDF AcroForm.
- Campos de texto, listas desplegables, checkbox y radio buttons.
- Guardado de formularios como copia editable o copia final.
- Organización de páginas: eliminar, agregar desde otro PDF, duplicar, insertar páginas en blanco, reordenar y giro permanente.
- Vista previa de PDF integrada en Explorador de Windows y Outlook clásico.
- Apertura del PDF actual en Microsoft Edge, Google Chrome u otra aplicación.
- Guardado mediante **Guardar como...** para preservar el archivo original.

## Integración con Windows

LepiPDF incluye un **Preview Handler x64** para visualizar archivos PDF directamente desde el panel de vista previa del Explorador y desde Outlook clásico.

## Tecnologías

Python · PDFium / pypdfium2 · C++ · Win32 API · Windows COM · IPreviewHandler · AcroForm · Tkinter · Pillow · pypdf · ReportLab · PyInstaller · Inno Setup

LepiPDF no ejecuta JavaScript arbitrario contenido dentro de los archivos PDF.
