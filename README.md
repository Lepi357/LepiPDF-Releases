# Lepi-PDF

**Visor y herramientas para trabajar con documentos PDF en Windows.**

Lepi-PDF es una aplicación de escritorio desarrollada por **Lepi Software / We-Soluciones**. Nació para resolver necesidades concretas de trabajo con documentos y reúne funciones de lectura, edición, conversión, organización e impresión en una sola herramienta.

## Funciones principales

- **Visualización:** abrir archivos PDF, navegar por páginas, buscar texto, aplicar zoom y ajustar al ancho o alto de la ventana.
- **Edición y anotaciones:** seleccionar y copiar texto, resaltar, agregar textos, fechas, formas y marcas; deshacer y rehacer cambios compatibles.
- **Organización de páginas:** insertar, eliminar, duplicar, reordenar y rotar páginas.
- **Membrete y pie de página:** incorporar textos e imágenes, centrarlos y ajustar su tamaño.
- **Formularios PDF:** completar campos interactivos y guardar una copia del documento.
- **Conversión:** exportar contenido de un PDF a **Word (.docx)** o **Excel (.xlsx)** para editarlo. La conservación del formato depende de la estructura del PDF original.
- **Impresión:** configurar páginas, orientación, varias páginas por hoja y doble faz cuando la impresora lo permita.
- **Vista previa en Windows:** visualizar archivos PDF desde el Explorador de archivos y Outlook clásico, con opciones de zoom, ajuste de página y rotación.
- **Actualizaciones:** comprobar si hay una nueva versión en GitHub y verificar la integridad de la descarga mediante SHA-256.

## Descargar Lepi-PDF

**[Ver y descargar la última versión publicada](https://github.com/Lepi357/LepiPDF-Releases/releases/latest)**

**[Descarga directa del instalador para Windows x64](https://github.com/Lepi357/LepiPDF-Releases/releases/latest/download/LepiPDF_Setup_x64.exe)**

El instalador y el archivo de verificación SHA-256 están disponibles en los archivos adjuntos de cada publicación. El enlace directo funciona mientras se mantenga el nombre compatible `LepiPDF_Setup_x64.exe` en la versión más reciente.

## Requisitos

- Windows 10 u 11, de 64 bits.
- Para la integración de vista previa, usar el Explorador de Windows u Outlook **clásico** compatible.

## Privacidad y seguridad

Lepi-PDF procesa los documentos localmente. La comprobación de actualizaciones utiliza GitHub. Los instaladores publicados incluyen un archivo de verificación SHA-256.
